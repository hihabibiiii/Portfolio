# 🌐 Personal Portfolio Website

🚀 A fully responsive personal portfolio website showcasing projects, skills, and experience with SEO optimization and analytics integration.

---

## 📌 Overview

This is a professional **multi-page portfolio website** designed to highlight my work as a **Data Scientist and Full Stack Developer**.

The portfolio is optimized for performance, SEO, and user experience, making it suitable for recruiters and clients.

---

## 🚀 Features

✔ Multi-page website (Home, About, Projects, Contact)
✔ Fully responsive design
✔ SEO optimized (sitemap.xml + robots.txt)
✔ Google Analytics integration
✔ Clean UI & structured layout
✔ Project showcase section

---

## 🧠 Tech Stack

* HTML
* CSS
* JavaScript
* SEO (Sitemap + Robots.txt)
* Google Analytics
